# Decision records

Each file records one decision: what we chose, why, and what we rejected. When someone asks why affectd works a certain way, the answer should be here.

To propose a change, copy `0000-template.md` to the next number, open a pull request, and link it from an issue. A record is accepted when the maintainers approve the pull request. Accepted records aren't edited later; a new record replaces an old one and says so.
