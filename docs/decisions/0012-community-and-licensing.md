# 0012. Licence and community rules

Status: Accepted, 6 November 2026

## Context

OpenSSF projects need clear, standard rules for contributions and conduct.

## Decision

- Apache License 2.0.
- Developer Certificate of Origin sign-off instead of a contributor licence agreement.
- Contributor Covenant as the code of conduct.
- GitHub Discussions as the only discussion channel, in English.
- A contributor ladder based on CNCF's template: contributor, reviewer, maintainer, emeritus.

## Consequences

Contributors find familiar rules, and the project meets OpenSSF's expectations without extra process.

## Alternatives considered

- A Discord or Slack server: more chat, but split conversations and another place to moderate.
